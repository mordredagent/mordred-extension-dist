# Store asset provenance and production

The promotional artwork was prepared from the official Mordred website brand
sources and refreshed on 2026-08-27 to match the website's current visual
system. The extension and Store icons are raster derivatives of the website's
exact favicon artwork. Neither the icon nor the submitted product screenshots
may be reconstructed or generated by AI.

## Official source

Source repository: `/Users/kazuko/dev/work/intmax/mordred-website`

| Brand element | Website source |
| --- | --- |
| Shield mark | `static/favicon.svg` |
| Reusable mark component | `src/lib/components/site/MordredMark.svelte` |
| Wordmark lockup | `scripts/og-image.html` (`.brand`) |
| Palette and typography | `src/app.css` |
| Existing campaign direction | `static/og.png` |

The canonical icon source is
`/Users/kazuko/dev/work/intmax/mordred-website/static/favicon.svg`. The exact
SVG is mirrored as `assets/brand/store-icon-128.svg`, then rasterized into the
four manifest sizes under `dist/icons/`. The 128px derivative is copied
byte-for-byte to `assets/brand/store-icon-128.png`.

The production palette follows the website:

- paper: `#ffffff`
- ink: `#1a1f36`
- ink deep: `#0e1120`
- copy: `#5a6478`
- signal: `#5851ff`
- signal on dark: `#9d99ff`

Promo typography uses the website's DM Sans and IBM Plex Mono direction, with
broadly available sans-serif and monospace fallbacks in the SVGs.

## Repository sources and final files

| Asset | Editable source | Upload/output file | Properties |
| --- | --- | --- | --- |

Keep the SVG files as editable masters for the website wordmark and promo
artwork. Keep the Store icon synchronized byte-for-byte with the icon packaged
in the submitted extension. The icon intentionally retains the favicon's
transparent padding; screenshots and promo tiles must remain opaque RGB images.

## Screenshots are separate

Promo artwork may use composed brand graphics, but Store screenshots must be
captures of the actual extension UI. Do not use generated, reconstructed, or
concept UI as a screenshot. See [`screenshots/README.md`](./screenshots/README.md)
for capture requirements.

`assets/screenshots/01-popup-onboarding-1280x800.png` was captured on
2026-08-27 from the submitted v0.2.2 `dist/` in a fresh isolated Chromium
profile. The real 380×560 popup was browser-rendered at 1.25× and centered on an
opaque 1280×800 canvas; no UI text, controls, or product state were recreated.
